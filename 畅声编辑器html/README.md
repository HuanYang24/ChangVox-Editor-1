# 畅声编辑器 - 虚拟歌声编辑器

畅声编辑器是一款基于HTML和C++开发的虚拟歌声编辑器，支持加载和使用UTAU声库进行歌声合成。

## 项目结构

- `index.html`: 编辑器的主界面，包含UI布局和基本交互
- `main.js`: 处理界面交互逻辑和与C++后端的通信
- `backend/`: C++后端代码目录（待实现）
- `assets/`: 静态资源文件目录
- `docs/`: 项目文档

## 功能特性

- 直观的钢琴卷帘界面，用于编辑音符
- 支持加载和管理UTAU声库
- 实时调整声音参数（响度、张力、气息等）
- 多音轨编辑功能
- 播放控制（播放、暂停、停止等）
- 支持多种语言的歌声合成

## 使用说明

### 基本操作
1. 打开 `index.html` 文件启动编辑器
2. 点击"加载声库"按钮选择UTAU声库文件
3. 在钢琴卷帘界面上点击并拖动创建音符
4. 使用右侧面板调整声音参数
5. 点击播放按钮试听效果

### 声库管理
- 支持标准UTAU格式的声库文件
- 可以切换不同的声库和预设

## 开发说明

### 前端开发
- UI基于HTML5、CSS3和JavaScript构建
- 使用现代CSS变量实现主题定制
- 响应式设计支持不同屏幕尺寸

### 后端开发
- C++后端负责歌声合成核心算法
- 计划通过WebAssembly或本地服务器与前端通信
- 支持UTAU声库的解析和使用

## 注意事项
- 当前版本为原型阶段，部分功能尚未完全实现
- 完整的歌声合成功能需要C++后端的支持
- 建议使用现代浏览器（Chrome、Firefox、Edge）以获得最佳体验
